# Project_PemrogramanWeb
Projek untuk membuat web sdg pada poin 8.3

Anggota Kelompok:
1. Ahmad Nala rayyan Saragih - 140810250061
2. Rafi Abdul Hikam - 140810250064
3. Muhammad Haikal Muzhoffar - 140810250082

## Fungsi
1. Halaman Materi/Artikel – konten edukasi tentang SDG 8.3 (kerja layak, pertumbuhan ekonomi, UMKM, dll)
2. Kategori Materi – pengelompokan topik (kewirausahaan, formalisasi usaha, akses keuangan, ketenagakerjaan)
3. Video/Modul Pembelajaran– embed video atau file materi (PDF/PPT) yang bisa diunduh
4. Forum Diskusi/Komentar – tempat bertanya atau berdiskusi di tiap materi
5. Pencarian & Filter Materi – memudahkan pengguna mencari topik tertentu
6.Dashboard Admin – untuk mengelola/upload materi baru

## Tujuan
1. Mengedukasi masyarakat tentang pentingnya SDG 8.3 (kerja layak & pertumbuhan ekonomi inklusif)
2. Menjadi media literasi digital seputar kewirausahaan dan UMKM
3. Meningkatkan kesadaran tentang pentingnya formalisasi usaha dan akses layanan keuangan
4. Menyediakan sumber belajar terstruktur yang mudah diakses kapan saja

## Target Pengguna
1. Mahasiswa/Pelajar	(Belajar & referensi tugas terkait SDG 8.3)
2. Pelaku UMKM/calon wirausaha	(Edukasi dasar tentang legalitas, keuangan, kewirausahaan)
3. Masyarakat umum	(Literasi tentang SDG 8.3)
4. Dosen/Pengajar	(Sumber materi tambahan untuk pengajaran)
5. Admin/Pengelola konten	(Mengelola & mengunggah materi)
